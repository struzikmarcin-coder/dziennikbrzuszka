Synchronizacja między telefonami

Wpisy zapisują się w pliku w Twoim prywatnym repo na GitHubie, więc widać je na każdym połączonym urządzeniu.

Jak zdobyć token
  1. Załóż na GitHubie prywatne repo na dane, np. dziennikbrzuszka-dane.
  2. Wejdź w GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access: Only select repositories i wybierz repo z danymi.
  4. Permissions → Repository permissions → Contents: Read and write. Nic więcej.
  5. Skopiuj token i wklej go tutaj na każdym telefonie.
